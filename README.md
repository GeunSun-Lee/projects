# Personal Projects

A collection of small personal projects built to strengthen software development skills, explore new technologies, and experiment with new ideas.

This repository serves as both a learning journal and a portfolio, documenting my continuous growth as a developer through hands-on practice.

## Purpose

The primary goals of this repository are to:

- Practice software engineering principles and best practices.
- Explore new frameworks, libraries, and technologies.
- Build small, focused applications to solve real-world problems.
- Continuously improve coding, testing, and project organization skills.
- Maintain a record of personal learning and development.

## Projects

| Project | Description |
|---------|-------------|
| todo-list | A basic Todo List application for learning application architecture and CRUD operations. |
| kanban_board | Tracks the progress of all projects using a Kanban workflow. |
| arithmetic-practice | A simple application for practicing basic arithmetic operations. |
